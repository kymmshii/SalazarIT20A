Sorting Algorithms Activity



Introduction



This Java program kay nagpakita sa tulo ka klase nga sorting algorithms:

Bubble Sort, 

Selection Sort, 

Insertion Sort.



Ang purpose ani nga program kay mao ang pag-arrange sa mga numbers gikan sa pinakagamay hangtod sa pinakadako. Gigamit ang usa ka original array ug gihimoan nig separate copies aron kada sorting algorithm makagamit sa same nga original numbers.



1. Bubble Sort



Ang Bubble Sort kay nagcompare sa duha ka number nga magtapad. Kung mas dako ang naa sa left kaysa sa naa sa tuo, ilang ibaylo ang ilang position.



Balik-balikon dayun hangtod ma-arrange na ang tanang number gikan sa pinakagamay hangtud sa pinakadako.



2. Selection Sort



Ang Selection Sort kay mangita sya sa pinakagamay nga number sa array. tas pag makita na niya iya dayun ibutang sa pinaka una



Sunod, mangita na pud siya sa pinakagamay nga number sa mga wala pa na arrange nga mga number. Padayonon niya hangtod mahuman ang sorting. 



3. Insertion Sort



Ang Insertion Sort kay kwaon niya ang isa ka number ug pangitaon niya ang sakto nga position aside sa mga number nga na-arrange na.



Kung naay mas dako nga number sa unahan, ibalhin niya aron mataagaan og space ang number nga gisulod.



Differences Between the Three Sorting Algorithms



Ang tulo ka algorithms parehas rag purpose pero lahi-lahi lang silag process.



Bubble Sort Magcompare sa magtapad nga number ug mag change sa ilang position kung need.

Selection Sort: Mangita sa pinakagamay nga number ug ibutang ni sa saktong position.

Insertion Sort: Magkuhag isa ka number ug isulod niya sa sakto nga lugar aside sa mga number nga na-arrange na.
